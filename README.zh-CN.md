# LOEWE Editorial Craft · 手作拼贴编辑风 Deck 生成技能

一个 agent 技能（skill），用来生成手作拼贴编辑风的横向翻页网页 PPT——视觉源自 LOEWE 180 周年刊物。

## 视觉语言

- **红蓝双电压**：朱砂红手写 × anagram 蓝大字标，一页一主一辅，永不同时抢戏
- **暖纸画布 + 深茄紫负空间**：正文走暖纸，封面/数据页走紫绒
- **拼贴母语**：撕边纸签、实底吊牌、色纸块骑缝、静物方块、大号衬线序号、手写批注
- **层级不用阴影**：用纸张叠压、错位实色影（3-4px）、撕边、静物探边表达前后关系

## 三条硬禁令（违反即返工）

1. **禁止细线装饰成分**——卡片描边、骑细彩条、行分隔线、中缝虚线、虚线网格、双细规线，一律不许出现。分隔交给留白、色块明度差、字级差
2. **禁止同质卡片复读**——「mono 小标+大字+一行说明」同骨架排排坐是 AI 舒适区；清单用编号式编辑排版，对比用明暗双版尺度差，时间轴用缎带轴+数字节点
3. **禁止内容载具旋转**——色版、卡片、吊牌、纸签、静物一律 rotate(0)。材质感来自纸/绒/漆/撕边/错位实色影，不来自倾斜。仅手写批注与小兽 ≤3° 例外

## 产出形态

单 HTML 横向翻页 deck，含三件交互：
- ← → 键盘翻页（回弹曲线）
- 目录行点击跳页
- 卡片点开克隆放大、点任意处还原

## 文件导航

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 技能入口：生成工作流、硬禁令、可探索的延伸方向 |
| `references/DESIGN.md` | 完整设计规范：色票、字体、组件、Do/Don't |
| `references/text-discipline.md` | 文字收束十条：kicker 制度、字数分档、最小字号、三声部纪律等 |
| `references/origin-story.md` | 原始素材拆解记录：四张素材 → 结构决策的映射 |
| `assets/sample-deck.html` | 12 页样张骨架，双击即可在浏览器翻页 |

## 用法

把 `.skill` 包装进你的 agent 环境，或把这个文件夹拷进你的技能目录。然后对 agent 说：「用罗意威那套做个方案」。
