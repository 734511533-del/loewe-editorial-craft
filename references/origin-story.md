# LOEWE Editorial Craft · 拆解说明

## 素材来源

四张公开影像，三个场景：
1. **产品硬照**：白色 Amazona 手袋 × 漆红摇椅，深茄紫绒面底，蓝色 LOEWE 大字标 + 红色手写「1846 MADRID」
2. **naive 理想国书店联乘**：米白墙面橱窗，红色剪影小兽贴花 + 玻璃贴花蓝字
3. **LOEWE Foundation Craft Prize**：樱花粉底静物（漆器 / 黑陶 / 编织物）

## 这套 DESIGN.md 的结构为什么长这样

每套素材的拆解结构由素材本身的「性格」决定，不走固定目录。这套的结构逻辑：

| 素材里观察到的 | 落成的结构 |
|---|---|
| 深茄紫产品照 vs 米白书店橱窗 vs 樱花粉静物 | 「双底画布 + 一变化底」的 surface 体系，而不是单一 primary |
| 蓝字大标和红手写永远不同时抢戏 | 「红蓝双电压，一页一主一辅」的使用规则，而不是并列 accent 色板 |
| 衬线大标 / 手写红字 / 编辑小字三个声音 | typography 按「三声部」组织，而不是 display→body 的常规梯队 |
| 小兽贴花、吊牌、撕边、微旋转 | 「拼贴元素」独立成章并替代阴影/圆角成为层级语言（Elevation 章整个改写） |
| 漆器/陶/藤/纸/绒五种真实材质 | colors 里专设「材质点缀色」组，textures 独立成顶层字段 |
| 目标产物是多页幻灯片系统 | Components 全部映射为页面级组件 + 图表语法 + 页面骨架表 |

## 复用到下一套素材时的拆解顺序

1. **先取样**——把素材图里真实出现的颜色吸出来（文本区要按颜色过滤取平均，直接点采样会采到背景）
2. **找性格词**——这套是「手作拼贴型编辑视觉」；下一套可能是「几何秩序」「科技冷峻」，性格词决定章节结构
3. **识别独有母题**——这套是小兽+吊牌+手写红字；每套素材都有 1-3 个别的系统里没有的东西，它们必须成为独立章节
4. **改写 Elevation/Shapes**——这两个章节最能体现「不是换汤不换药」：这套用拼贴叠压替代投影，下一套可能用玻璃、描边或网格
5. **最后写 Do/Don't**——禁令比用法更能锁定一套视觉的边界
